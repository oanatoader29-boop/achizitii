# Gestiune achizitii publice

Aplicatie pentru Serviciul Achizitii Publice: referate de necesitate si centralizari importate din Excel, nomenclator de necesitati, catalog de produse, PAAP generat automat, verificarea pragului de achizitie directa pe necesitate, evidenta contractelor cu alerte de expirare.

Cadru legal: Legea 98/2016 si HG 395/2016, in forma in vigoare la 01.01.2026.

## Utilizare
Deschideti pagina in Google Chrome sau Microsoft Edge si alegeti folderul comun din reteaua spitalului.

## Date
Pagina nu contine date. Toate datele se salveaza in fisierul `registru_achizitii.json` din folderul comun ales la deschidere, pe reteaua spitalului. Nu incarcati in acest depozit fisierul registrului sau copiile din subfolderul `copii`.
